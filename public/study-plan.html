📅 8-Week CompTIA A+ Study Plan

Structured week-by-week roadmap for comprehensive exam preparation (1-2 hours/day)

💡 How to Use This Plan

  • Consistency beats cramming: 1-2 hours daily for 8 weeks beats last-minute 12-hour marathon sessions
  • Hands-on practice: Don't just read — take apart old devices, configure VMs, practice troubleshooting
  • Active recall: Use flashcards, take practice tests, teach concepts to someone else
  • Adjust pacing: If you have IT experience, reduce time. If new to IT, add an extra week
  • Take both exams: Pass Core 1 (220-1201) first, then Core 2 (220-1202) — they build on each other
1

Mobile Devices & Laptops

Master smartphone/tablet features, laptop hardware components, input devices, and mobile connectivity

Topics to Study:
  • Smartphone vs. tablet vs. wearable device characteristics
  • Mobile connectivity: Wi-Fi, Bluetooth, NFC, cellular (IMEI, ICCID, IMSI)
  • Laptop hardware: keyboard removal, system board replacement, power states
  • Field-Replaceable Units (FRUs) — what can technicians replace
  • Mobile device synchronization: iCloud, Google, Exchange ActiveSync
Practice: Identify components on a smartphone/laptop. Set up email sync on iOS/Android. Practice removing a laptop keyboard.
2

Networking Fundamentals

Network types, TCP/IP, IP addressing, ports, protocols, DNS/DHCP, VLANs, and SOHO setup (23% of Core 1)

Topics to Study:
  • Network types: PAN, LAN, WLAN, MAN, WAN, WWAN
  • TCP/IP model (4 layers) vs. OSI model (7 layers)
  • IPv4 addressing, subnetting, CIDR notation (/24, /25, etc.)
  • IPv6 basics: link-local, multicast, anycast, SLAAC
  • Critical ports: 22 (SSH), 53 (DNS), 67/68 (DHCP), 80/443 (HTTP/S), 389/636 (LDAP)
  • Network hardware: switches (Layer 2), routers (Layer 3), firewalls
  • SOHO router setup: DHCP, port forwarding, wireless security
Practice: Calculate subnets. Identify what layer routers/switches operate on. Set up a home network in a VM.
3

Hardware & Peripherals

Motherboards, CPUs, RAM, storage, printers, expansion cards, power supplies (25% of Core 1)

Topics to Study:
  • Motherboard form factors: ATX, mATX, mini-ITX, E-ATX
  • CPU sockets: LGA 1700, LGA 1851 (Intel), AM4, AM5 (AMD) — NOT interchangeable across generations
  • RAM: DDR4 vs. DDR5 (different notches!), dual-channel requirements, ECC RAM
  • Storage: HDD (RPM), SSD/NVMe (PCIe speeds), RAID levels (0, 1, 5, 6, 10)
  • Power supplies: wattage, 80+ ratings, connectors (24-pin ATX, 8-pin EPS, 6+2 PCIe, SATA)
  • Expansion cards: PCIe versions (3.0, 4.0, 5.0), GPUs, sound cards, RAID controllers
  • Cooling: thermal paste, CPU heatsinks, case fans, TDP
  • Printer types: inkjet, laser, thermal, impact, 3D printing
Practice: Identify motherboard components. Calculate PSU wattage. Practice RAM installation. Learn the 6-step troubleshooting methodology.
4

Virtualization, Cloud & IoT

Hypervisors, VMs, cloud models (IaaS/PaaS/SaaS), IoT security, disaster recovery

Topics to Study:
  • Type 1 hypervisors: VMware ESXi, Hyper-V Server (bare-metal)
  • Type 2 hypervisors: VirtualBox, VMware Workstation (host OS-based)
  • VM configuration: snapshots, cloning, resource allocation
  • Cloud models: IaaS (AWS EC2), PaaS (Azure App Service), SaaS (Office 365)
  • Cloud concepts: elasticity, scalability, shared responsibility model
  • IoT security: default passwords, firmware updates, segmentation
  • Backup types: full, incremental, differential
  • Disaster recovery: RPO, RTO, failover
Practice: Create a VM in VirtualBox. Take a snapshot, make changes, revert. Understand the cloud responsibility matrix.
5

Operating Systems (Core 2)

Windows tools, Linux commands, macOS basics, OS installation, updates, file systems (28% of Core 2)

Topics to Study:
  • Windows tools: Device Manager, Disk Management, Group Policy, Services, Task Scheduler
  • Windows CLI: CMD vs. PowerShell, ipconfig, systeminfo, sfc /scannow, chkdsk /f
  • Linux commands: ls, cd, sudo, chmod, chown, ps, top, systemd
  • macOS: Finder, Terminal, Activity Monitor, Disk Utility, Time Machine
  • File systems: NTFS vs. FAT32 vs. ext4 vs. APFS
  • OS installation: clean install, upgrade, boot order, BIOS/UEFI
  • Windows editions: Home (no domain join, no BitLocker), Pro, Enterprise
Practice: Install Windows/Linux in a VM from ISO. Use Windows PowerShell. Master the CLI commands for your OS.
6

Security (Core 2)

Threats, authentication, wireless security, malware, physical security, compliance (28% of Core 2)

Topics to Study:
  • Threat types: virus, worm, trojan, spyware, ransomware, adware, fileless malware, rootkit, keylogger
  • Authentication: passwords, PIN, biometric, MFA (2FA), certificate-based
  • Wireless security: WEP (broken), WPA (weak), WPA2 (strong), WPA3 (strongest with SAE)
  • Encryption: BitLocker (Windows Pro+), FileVault (macOS), AES, TLS 1.2/1.3
  • Social engineering: phishing, vishing, smishing, whaling, pretexting, tailgating
  • Physical security: access control, surveillance, locked cabinets, badge readers
  • Data destruction: wiping, degaussing (magnetic only), physical destruction, certificate of destruction
  • Regulations: GDPR, HIPAA, PCI-DSS, SOX
Practice: Identify malware types. Set up MFA on personal accounts. Review GDPR/HIPAA requirements.
7

Troubleshooting & Operations

6-step methodology, professional communication, documentation, support tickets (Core 1 & 2)

Topics to Study:
  • 6-step troubleshooting: Identify, Establish theory, Test theory, Establish plan, Implement, Verify (IETEVD)
  • Professional communication: email etiquette, phone skills, documentation, ticket tracking
  • Change management: notification, testing, rollback, approval
  • IT documentation: runbooks, network diagrams, asset inventory, disaster recovery plans
  • Common symptoms: random shutdowns (PSU), won't POST (RAM/CPU), BSOD (driver/OS)
  • Hardware troubleshooting: POST codes, Q-LEDs, diagnostic tools, loopback plugs
  • Software troubleshooting: Safe Mode, Clean Boot, Event Viewer, Device Manager
  • Network troubleshooting: ping, ipconfig, nslookup, tracert, arp -a
Practice: Practice the 6-step methodology on sample scenarios. Write professional support ticket responses.
8

Review & Practice Exams

Take full practice exams, identify weak areas, final review, schedule real exams

Activities:
  • Take a full Core 1 (220-1201) practice exam (90 minutes, ~90 questions)
  • Review failed questions — identify patterns (networking? hardware? troubleshooting?)
  • Take a full Core 2 (220-1202) practice exam
  • Study weak domains identified in practice exams
  • Review exam tips and traps in the study guide
  • Answer every question on the real exam (no penalty for wrong answers!)
  • Schedule your exams at Pearson VUE — register 1-2 weeks before
Practice: Take multiple full practice exams. Aim for 80%+ on practice before scheduling real exams.

Port Numbers (Rule of 22)

"22 is always secure, 23 is never secure"

• Port 22 = SSH (encrypted)
• Port 23 = Telnet (unencrypted, OBSOLETE)
One number apart, opposite security!

Cloud Service Models

"You use it, they run it" (SaaS) / "You build it, they manage it" (PaaS) / "You control it, they own it" (IaaS)

• SaaS: Gmail, Office 365
• PaaS: Azure App Service
• IaaS: AWS EC2
Remember: Responsibility increases as you go down

Critical Port Numbers to Know

"22 secure, 53 names, 67/68 assigns, 80/443 web"

• 22 = SSH/SFTP
• 53 = DNS
• 67/68 = DHCP
• 80/443 = HTTP/HTTPS
• 389/636 = LDAP/LDAPS

⚠️ Common Exam Traps & Wrong Answers

  • DDR4 works in DDR5 slots: WRONG — different notch positions. They're incompatible!
  • Windows Home can be RDP HOST: WRONG — Home can be RDP CLIENT only. Pro required to host.
  • APIPA means network is working: WRONG — 169.254.x.x means DHCP failed!
  • Formatting permanently deletes data: WRONG — format only removes file system. Use secure wipe tools.
  • Antivirus alone is sufficient: WRONG — need defense in depth: AV + firewall + patches + MFA + encryption.
  • Remote Wipe first for lost phone: WRONG — use Remote LOCK first! Wipe only if confirmed stolen.
  • Switches broadcast like hubs: WRONG — switches forward only to correct port using MAC table.
  • Degaussing erases SSDs: WRONG — degaussing works only on magnetic media. Destroy or secure-erase SSDs.

✅ Exam Day Tips

  • Answer every question: You don't lose points for wrong answers — always guess!
  • Flag tough questions: Mark questions you're unsure of and return to them if time allows.
  • Read questions carefully: Look for qualifiers: "BEST", "FIRST", "NOT", "MOST likely"
  • Eliminate wrong answers: Often easier than finding the right answer — narrows choices
  • Time management: ~60 seconds per question. If stuck, flag and move on.
  • Take both exams in same session: Schedule both on same day or consecutive days to stay in "exam mode"
  • Bring ID and arrive early: Proctors are strict about time and identification requirements
