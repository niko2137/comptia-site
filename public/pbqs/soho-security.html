CompTIA A+ Core 2 — Performance-Based Question

Instructions

You are a technician tasked with securing a small office/home office (SOHO) network. The router currently has multiple security vulnerabilities that need to be addressed.

  • Exercise 1: Review the router's current configuration and toggle each insecure setting to its secure state.
  • Exercise 2: Identify the security vulnerability that caused each breach scenario.
  • Click Check Answers to see your score for both exercises.
💡 Pro Tip

Default credentials = instant compromise. WPS is ALWAYS a vulnerability. Guest network + client isolation is the #1 recommendation for SOHO security.
