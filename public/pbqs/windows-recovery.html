Exam Tips — Windows Recovery Environment

  • Startup Repair = always try FIRST for generic boot failures
  • F8 does NOT work in Windows 10/11 — use Shift+Restart or WinRE automatic trigger (3 failed boots)
  • System Restore does NOT affect personal files — only system settings, drivers, and programs
