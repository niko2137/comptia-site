Network Ports Quick Reference

Essential ports for the CompTIA A+ 220-1200 exam — sorted by port number

Port Protocol TCP/UDP Description
20/21 FTP TCP File transfer (20=data, 21=control)
22 SSH/SFTP TCP Encrypted remote access / file transfer
23 Telnet TCP Unencrypted remote access (insecure, legacy)
25 SMTP TCP Send email (outbound)
53 DNS TCP/UDP Domain name resolution
67/68 DHCP UDP IP address assignment (67=server, 68=client)
80 HTTP TCP Unencrypted web browsing
110 POP3 TCP Receive email (downloads, removes from server)
143 IMAP TCP Receive email (syncs across devices)
161/162 SNMP UDP Network device monitoring
389 LDAP TCP/UDP Directory services (Active Directory)
443 HTTPS TCP Encrypted web browsing (TLS/SSL)
445 SMB TCP Windows file/printer sharing
587 SMTP (submission) TCP Email submission with STARTTLS
636 LDAPS TCP Encrypted LDAP
993 IMAPS TCP Encrypted IMAP
995 POP3S TCP Encrypted POP3
3389 RDP TCP Windows Remote Desktop
5060/5061 SIP TCP/UDP VoIP call setup (5061=encrypted)
5900 VNC TCP Cross-platform screen sharing

💡 Quick Tips

  • Secure versions always have higher port numbers (110→995, 143→993)
  • SSH does double duty: remote access AND file transfer (SFTP)
  • DHCP uses UDP because speed matters more than guaranteed delivery for IP assignment
  • Port 445 (SMB) should NEVER be exposed to the internet
