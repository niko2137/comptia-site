Windows Troubleshooting Commands

Essential CLI commands for the CompTIA A+ 220-1200 exam — know what each does and when to use it

Command Purpose Key Switches When to Use
ipconfig IP configuration /all, /release, /renew, /flushdns First step for any network issue
ping Test connectivity -t (continuous), -n (count) Verify host reachable
tracert Trace route to host (none common) Find where packets stop
nslookup Test DNS resolution (server name) DNS issues, wrong IP returned
netstat Active connections -a (all), -n (numeric), -b (process) Find open ports, suspicious connections
sfc /scannow Repair system files (none) Corrupted Windows files
DISM /Online /Cleanup-Image /RestoreHealth Fix component store (none) Run BEFORE retrying failed sfc
chkdsk Disk integrity /f (fix errors), /r (bad sectors) Disk errors, file corruption
bootrec Fix bootloader /fixmbr, /fixboot, /rebuildbcd Windows won't boot
msconfig System configuration (GUI) Isolate startup/service conflicts
gpupdate /force Refresh Group Policy (none) GPO not applying
diskpart Disk management CLI list disk, clean, convert gpt Advanced partition work
robocopy Robust file copy /mir, /e, /z (resume) Large file migrations
shutdown Remote/scheduled shutdown /s, /r, /t (seconds) Restart remote PCs

Troubleshooting Flows

🌐 Network Issues

ipconfig → ping 127.0.0.1 → ping gateway → ping external → nslookup

💻 Boot Failures

WinRE → Startup Repair → bootrec /rebuildbcd → sfc → DISM

🔧 System Corruption

sfc /scannow → if fails → DISM /RestoreHealth → retry sfc

🐢 Slow System

Task Manager → Resource Monitor → check startup items (msconfig)
