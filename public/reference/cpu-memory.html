🧠 CPU & Memory Deep Dive

Current CPU socket types and DDR RAM specifications for the CompTIA A+ 220-1200 exam

LGA vs. PGA socket architecture comparison

CPU Socket Types

The CPU socket on the motherboard must match the CPU's socket type exactly — sockets are generation-specific.

SocketManufacturerNotes
LGA 1700IntelIntel 12th, 13th, and 14th gen Core processors. Pins on motherboard.
LGA 1851Intel2024+. Arrow Lake / "Core Ultra Series 2" desktop CPUs. DDR5-only.
AM4AMDRyzen 1000–5000 series. PGA (pins on CPU) — one of the longest-lasting sockets in history.
AM5AMDRyzen 7000 series and newer. LGA-style (pins moved to motherboard). Expected to support multiple future generations.
SP3 / SP5AMD (Server)SP3 = EPYC Naples/Rome/Milan. SP5 = EPYC Genoa/Bergamo (Zen 4). Not interchangeable.
LGA 4677Intel (Server)Intel Xeon Scalable server processors.

DDR RAM Types

TypeSpeed RangeVoltageNotes
DDR31066–1866 MHz1.35–1.5VLegacy. NOT compatible with DDR4/DDR5 slots.
DDR42133–3200+ MHz1.2VCurrent mainstream standard 2016–2023.
DDR54800–7200+ MHz1.1VRequired for Intel 12th gen+ and AMD Ryzen 7000+. Higher bandwidth/capacity.
ECC RAMVariesVariesError-Correcting Code — detects/corrects single-bit errors. Used in servers/workstations.

💡 RAM Installation Rules

  • Dual-Channel: install matched pairs in the correct color-coded slots (usually 1&3 or 2&4) to double memory bandwidth
  • Capacity: mismatched sizes default to single-channel — install matched pairs (e.g., 2×8GB)
  • Max capacity is determined by the motherboard chipset and CPU, not just the number of slots

⚠️ Exam Traps

DDR4 and DDR5 slots are physically different and NOT interchangeable — DDR5 DIMMs have a different notch position. An LGA 1700 CPU will NOT fit an LGA 1851 socket (different pin layout) even though both are current Intel sockets — always verify exact socket compatibility before purchasing.
