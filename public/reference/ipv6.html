🔢 IPv6 & SLAAC Quick Reference

Address notation, prefix types, address types, and Stateless Address Autoconfiguration for the CompTIA A+ 220-1200 exam

IPv6 notation compression rules

IPv6 Address Basics

FeatureDescription
Format128-bit, 8 groups of 4 hex digits separated by colons
Loopback::1
Link-localfe80::/10
BroadcastNone — IPv6 uses multicast and anycast instead
Auto-configSLAAC (Stateless Address Autoconfiguration)
Standard LAN prefix/64

Notation Compression Rules

Full: 2001:0db8:85a3:0000:0000:8a2e:0370:7334
↓ Rule 1 — drop leading zeros in each group
2001:db8:85a3:0:0:8a2e:370:7334
↓ Rule 2 — replace ONE run of all-zero groups with ::
2001:db8:85a3::8a2e:370:7334

The double-colon :: can only appear once per address — otherwise the address would be ambiguous.

Common IPv6 Prefix Types

PrefixPurposeDetails

ff00::/8MulticastOne-to-many delivery; no direct IPv4 equivalent

IPv6 Address Types

TypeDescription
UnicastOne-to-one — standard type for most communication
MulticastOne-to-many — single packet sent to multiple destinations
AnycastDelivered to the nearest of several destinations — used for DNS/CDN load balancing

How SLAAC Works

  1. Router Advertisement — the router periodically sends RA messages containing the network prefix (typically /64)
  2. Interface Identifier — the device generates the host portion (last 64 bits) via EUI-64 (from the MAC address) or Privacy Extensions (randomized)
  3. Address Formation — the device combines the router's prefix with its generated identifier
  4. Duplicate Address Detection (DAD) — the device verifies no other device is using the same address
Router advertises prefix: 2001:db8:abcd:12::/64
Device MAC: 00:1A:2B:3C:4D:5E
EUI-64 identifier: 021a:2bff:fe3c:4d5e
→ Final address: 2001:db8:abcd:12:021a:2bff:fe3c:4d5e/64

💡 SLAAC vs. DHCPv6

  • SLAAC = Stateless — no server tracks assignments
  • DHCPv6 = Stateful — server manages and tracks address assignments
  • Many networks use both: SLAAC for address assignment + DHCPv6 for DNS/domain info

⚠️ Exam Traps

fe80:: link-local addresses are automatically assigned to every IPv6 interface and cannot be removed. If a device only has a fe80:: address (no global address), check whether the router is sending Router Advertisements or whether SLAAC/DHCPv6 is functioning.

IPv6 has no subnet mask — it uses prefix length (like /64) instead, and there is no broadcast to worry about at all.
