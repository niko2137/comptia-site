📖 CompTIA A+ Comprehensive Glossary

220-1201 (Core 1) & 220-1202 (Core 2) — Complete study reference with 100+ essential terms

API

Application Programming Interface. A set of rules and protocols that allows different software applications to communicate and exchange data.

Networking

APIPA

Automatic Private IP Addressing. An address in the range 169.254.x.x automatically assigned when a device cannot reach a DHCP server. Indicates DHCP failure.

Networking

ARP

Address Resolution Protocol. A Layer 2/3 protocol that resolves IP addresses to MAC addresses on the local network. Used for device discovery.

Networking

Bandwidth

The maximum data transmission rate over a connection, measured in bits per second (Mbps, Gbps). Determines maximum theoretical speed.

Networking

BIOS

Basic Input/Output System. Firmware that runs before the OS. Initializes hardware and boots the operating system. Being replaced by UEFI.

Hardware

BitLocker

Windows full-disk encryption feature. Requires TPM 2.0 and Windows Pro or higher. Encrypts entire drive including OS and personal files.

Security

Bluetooth

Short-range wireless standard (typically up to 33 feet). Used for connecting peripherals like headsets, mice, and keyboards. Different classes have varying ranges.

Mobile/Networking

Boot Sector

The first sector of a disk (typically 512 bytes) that contains the bootloader code. Tells the system how to start the operating system.

Storage

BYOD

Bring Your Own Device. A workplace policy allowing employees to use personal mobile devices for work purposes. Requires MDM and security controls.

Security

Cache

Fast temporary memory that stores frequently accessed data. Levels: L1 (CPU cache), L2 (per core), L3 (shared among cores). Speeds up performance.

Hardware

CalDAV

Calendar Delegation Access Protocol. A standard protocol for synchronizing calendar data between devices and servers. Used by iCloud, Google Calendar, and corporate systems.

Mobile

CardDAV

Contact Card Delegation Access Protocol. A standard for synchronizing contacts across devices. Used by iCloud, Google Contacts, and Enterprise systems.

Mobile

CCNA

Cisco Certified Network Associate. Advanced networking certification. CompTIA A+ is foundational; CCNA builds on networking knowledge.

Certification

CIDR

Classless Inter-Domain Routing. Notation for IP addresses using a prefix length (e.g., 192.168.1.0/24). More efficient than Class-based addressing.

Networking

CMOS

Complementary Metal-Oxide-Semiconductor. The battery-backed memory that stores BIOS settings. Powered by a CR2032 coin cell battery on the motherboard.

Hardware

CPU

Central Processing Unit. The main processor chip in a computer. Executes instructions. Modern CPUs use socket types like LGA 1700 (Intel) or AM5 (AMD).

Hardware

DDR4 / DDR5

Double Data Rate RAM. DDR4 runs at 2133-3200+ MHz; DDR5 at 4800-7200+ MHz. NOT interchangeable — different notch positions prevent accidental insertion.

Hardware

DHCP

Dynamic Host Configuration Protocol. Automatically assigns IP addresses to devices on a network. Uses ports 67 (server) and 68 (client).

Networking

DNS

Domain Name System. Translates human-readable domain names (google.com) to IP addresses (142.250.x.x). Uses port 53 (TCP/UDP).

Networking

EAS

Exchange ActiveSync. Microsoft protocol for syncing email, contacts, and calendar in a single connection. The preferred corporate mobile sync solution.

Mobile

ECC RAM

Error-Correcting Code RAM. Detects and corrects single-bit memory errors. Used in servers and workstations where data integrity is critical.

Hardware

ESD

Electrostatic Discharge. Static electricity that can damage sensitive components. Prevented using antistatic wrist straps, mats, and proper grounding.

Safety

Ethernet

Wired networking standard using twisted-pair cables (Cat5e, Cat6, Cat7). Standard for local area networks. Uses RJ-45 connectors.

Networking

FileVault

macOS full-disk encryption. Built into all macOS versions. Similar to Windows BitLocker — encrypts entire drive including OS and user files.

Security

FRU

Field-Replaceable Unit. Components that technicians can replace without returning the device to the manufacturer. Examples: RAM, hard drives, Wi-Fi cards.

Hardware

FTP

File Transfer Protocol. Unencrypted file transfer protocol using port 21 (control) and port 20 (data). Deprecated — use SFTP instead.

Networking

GPU

Graphics Processing Unit. Dedicated processor for rendering graphics and video. Connected to PCIe x16 slot. Requires separate power (6+2 pin connector).

Hardware

GUID

Globally Unique Identifier. A 128-bit value used to uniquely identify resources. Different from GUIDs used in Windows (which are 16-byte values).

Software

GPT

GUID Partition Table. Modern partition format supporting drives larger than 2 TB. Replaces MBR. Used on modern systems, required for UEFI.

Storage

Hypervisor

Virtual machine monitor software. Type 1: runs on hardware (ESXi, Hyper-V Server). Type 2: runs on host OS (VirtualBox, VMware Workstation).

Virtualization

Hz

Hertz. Unit of frequency representing cycles per second. RAM speed measured in MHz/GHz; refresh rate measured in Hz (60 Hz = 60 cycles/sec).

Hardware

I2C

Inter-Integrated Circuit. Low-speed protocol for communicating between components on a motherboard. Used for BIOS settings, temperature sensors, etc.

Hardware

ICCID

Integrated Circuit Card Identifier. A 19-22 digit number unique to a SIM card (or eSIM). Identifies the SIM card itself, not the user.

Mobile

IMEI

International Mobile Equipment Identity. A 15-digit identifier for cellular device hardware. Used to blacklist stolen phones. NOT unique to the user.

Mobile

IMSI

International Mobile Subscriber Identity. A 15-digit (or fewer) ID unique to the mobile subscriber. Used for roaming charges and billing.

Mobile

IMAP

Internet Message Access Protocol. Email protocol that keeps mail on server, syncs across devices. Port 143 (plain), 993 (SSL/TLS). Recommended over POP3.

Networking

IoT

Internet of Things. Network of connected physical devices with sensors that communicate over the internet. Examples: smart home devices, fitness trackers.

Networking

IP

Internet Protocol. Foundation protocol for routing packets between networks. Current versions: IPv4 (32-bit), IPv6 (128-bit). Operates at OSI Layer 3 (Network).

Networking

IPAM

IP Address Management. System for managing IP address allocation and tracking. Important for enterprise networks with thousands of devices.

Networking

ISP

Internet Service Provider. Company that provides Internet connectivity to consumers. Examples: Comcast, Verizon, AT&T.

Networking

LDAP

Lightweight Directory Access Protocol. Protocol for querying directory services (Active Directory). Port 389 (plain), 636 (LDAPS encrypted). Used for user lookups.

Networking

LGA

Land Grid Array. CPU socket type with pins on the motherboard socket (not on the CPU). Standard for modern Intel processors. Different versions (LGA 1200, 1700, 1851, etc.) are incompatible.

Hardware

LTE

Long Term Evolution. 4G cellular standard. Provides faster data than 3G. Being replaced by 5G in modern networks.

Mobile

MAC

Media Access Control. Layer 2 (Data Link) address. 48-bit address in format XX:XX:XX:XX:XX:XX. Used to identify devices on local networks. First 3 octets = manufacturer OUI.

Networking

MBR

Master Boot Record. Legacy partition format supporting drives up to 2 TB. Replaced by GPT on modern systems.

Storage

MFA

Multi-Factor Authentication. Authentication requiring more than one verification factor. Examples: password + phone code, password + fingerprint. Also called 2FA/3FA.

Security

MHz

Megahertz. One million cycles per second. Used to measure CPU and RAM speed. 1000 MHz = 1 GHz.

Hardware

NFC

Near Field Communication. Short-range wireless (1-2 inches). Used for contactless payments (Apple Pay, Google Pay) and quick device pairing (Android Beam).

Mobile

NTP

Network Time Protocol. Synchronizes system clocks across devices. Uses port 123 (UDP). Critical for SSL certificate validation and log timestamps.

Networking

NVMe

Non-Volatile Memory Express. Ultra-fast storage interface using PCIe. Speeds: PCIe 3.0 (~3500 MB/s), PCIe 4.0 (~7000 MB/s), PCIe 5.0 (~14000 MB/s).

Storage

OAuth

Open Authorization. Protocol allowing third-party apps to access user data without sharing passwords. Used for single sign-on (Google, Facebook, Microsoft logins).

Security

OS

Operating System. Software that manages computer hardware and provides services to applications. Examples: Windows, macOS, Linux, Android, iOS.

Software

OSI

Open Systems Interconnection. 7-layer reference model for network communication. Layers: Physical, Data Link, Network, Transport, Session, Presentation, Application.

Networking

OUI

Organizationally Unique Identifier. The first 3 octets (24 bits) of a MAC address. Identifies the manufacturer of the network adapter.

Networking

PAT

Port Address Translation. Multiple internal IP addresses share one public IP by using different port numbers. Enables many devices to access internet with one public IP.

Networking

PBQ

Performance-Based Question. Interactive exam question requiring hands-on troubleshooting or configuration. Tests practical skills, not just knowledge.

Exam

PCIe

PCI Express. Serial expansion bus for connecting peripherals. Versions: 3.0 (16 GB/s x16), 4.0 (32 GB/s x16), 5.0 (64 GB/s x16).

Hardware

PGA

Pin Grid Array. CPU socket type with pins on the CPU (not motherboard socket). Standard for AMD processors. Different versions are incompatible.

Hardware

PIN

Personal Identification Number. Secret numeric code used for authentication. Common on SIM cards and mobile devices for unlock protection.

Security

POP3

Post Office Protocol version 3. Email protocol that downloads mail from server (typically deletes server copy). Port 110 (plain), 995 (SSL/TLS). Legacy — use IMAP instead.

Networking

PRL

Preferred Roaming List. List of frequencies/towers on a cellular device. Updates pushed automatically via OTA. Allows device to connect to correct cellular network while roaming.

Mobile

PSU

Power Supply Unit. Converts wall power (AC) to regulated DC power (+3.3V, +5V, +12V) for computer components. Specifications: wattage, efficiency rating (80+ Bronze/Gold/Platinum).

Hardware

QoS

Quality of Service. Network feature that prioritizes certain traffic types. Example: prioritize video streaming over file downloads to prevent buffering.

Networking

RAID

Redundant Array of Independent Disks. Disk storage system combining multiple drives. RAID 0 (striping), RAID 1 (mirroring), RAID 5/6 (striping + parity), RAID 10 (stripe of mirrors).

Storage

RAM

Random Access Memory. Fast volatile memory used for running programs and storing temporary data. Lost when powered off. Types: DDR3, DDR4, DDR5.

Hardware

RDP

Remote Desktop Protocol. Windows graphical remote access protocol. Port 3389. Provides full desktop experience. NEVER expose to internet without VPN.

Networking

RFID

Radio-Frequency Identification. Wireless technology using radio waves to identify objects. Range varies from inches (passive) to 100+ feet (active). Used in asset tracking.

Networking

ROM

Read-Only Memory. Non-volatile memory containing firmware. Examples: BIOS/UEFI on motherboard. Data persists when powered off.

Hardware

RPM

Revolutions Per Minute. Speed at which a hard disk drive's platters spin. Common speeds: 5400 RPM (laptop HDDs), 7200 RPM (desktop HDDs). Faster = better performance, more heat.

Storage

RTC

Real-Time Clock. Circuit on motherboard powered by CMOS battery that maintains system time even when PC is powered off. Backed by CR2032 coin cell.

Hardware

SAE

Simultaneous Authentication of Equals. Wi-Fi 6+ encryption protocol used with WPA3. More secure than WPA2's 4-way handshake.

Security

SATA

Serial ATA. Interface for hard drives and SSDs. Speed: SATA II (3 Gbps), SATA III (6 Gbps). Connections: 7-pin data, 15-pin power.

Storage

SCSI

Small Computer System Interface. Legacy parallel interface for storage devices. Largely replaced by SATA for consumer systems. Still used in enterprise (SAS).

Storage

SD Card

Secure Digital Card. Removable flash storage used in cameras and mobile devices. Versions: SD (2 GB), SDHC (32 GB), SDXC (2 TB).

Storage

SFTP

SSH File Transfer Protocol. Secure file transfer over SSH. Replaces unencrypted FTP. Uses port 22 (same as SSH). Data encrypted in transit.

Networking

SLA

Service Level Agreement. Contract defining service availability, uptime, response time, and penalties for failures. Common in cloud/hosted services.

Business

SMART

Self-Monitoring Analysis and Reporting Technology. Built-in monitoring on hard drives and SSDs that predicts failures. Alerts when problems detected.

Storage

SMB

Server Message Block. Windows file and printer sharing protocol. Port 445. Used by ransomware attacks — keep systems patched and firewalled.

Networking

SMTP

Simple Mail Transfer Protocol. Protocol for sending outgoing email. Port 25 (server-to-server), 587 (client submission with STARTTLS), 465 (implicit SSL).

Networking

SNMP

Simple Network Management Protocol. Protocol for network monitoring and management. Port 161 (queries), 162 (trap alerts). Uses UDP.

Networking

SOHO

Small Office / Home Office. Network setup for 1-10 users. Uses consumer-grade routers, DHCP, NAT. Minimal security vs. enterprise networks.

Networking

SSD

Solid State Drive. Storage using flash memory (no moving parts). Faster, more durable, cooler than HDDs. Prices: SATA (~$0.10/GB), NVMe (~$0.08/GB).

Storage

SSH

Secure Shell. Encrypted remote command-line access. Port 22. Replaces unencrypted Telnet. Used for Linux/Unix server administration and secure file transfer (SFTP).

Networking

SSL / TLS

Secure Sockets Layer / Transport Layer Security. Encryption protocol for securing data in transit. SSL deprecated; use TLS 1.2 or 1.3. Used for HTTPS, SMTPS, IMAPS, etc.

Security

SSID

Service Set Identifier. Wi-Fi network name. Broadcast publicly so devices can discover and connect to the network. Can be hidden (not recommended).

Networking

TCP

Transmission Control Protocol. Connection-oriented Layer 4 transport protocol ensuring reliable, ordered data delivery. Used for: HTTP, HTTPS, FTP, SMTP, SSH, Telnet.

Networking

TCP/IP

Transmission Control Protocol / Internet Protocol. 4-layer networking model: Application, Transport, Internet, Network Access. The protocol suite running the internet.

Networking

TDP

Thermal Design Power. Maximum heat output (in watts) a CPU produces. Used to size cooling solutions. Higher TDP CPUs need better coolers.

Hardware

Telnet

Unencrypted remote access protocol. Port 23. Sends passwords in plain text. Completely obsolete — NEVER use. Replaced by SSH.

Networking

TPM

Trusted Platform Module. Chip storing cryptographic keys and enabling BitLocker, Windows Hello, Secure Boot. TPM 2.0 required for Windows 11.

Security

UDP

User Datagram Protocol. Connectionless Layer 4 transport protocol — fast but unreliable (no delivery guarantee). Used for: DNS, DHCP, NTP, SNMP, VoIP, streaming.

Networking

UEFI

Unified Extensible Firmware Interface. Modern replacement for BIOS. Supports drives larger than 2 TB (requires GPT partitioning). Enables Secure Boot.

Hardware

USB

Universal Serial Bus. Standard for connecting peripherals. Versions: 2.0 (480 Mbps), 3.0 (5 Gbps), 3.1 (10 Gbps), 3.2 (20 Gbps), 4.0 (40 Gbps).

Hardware

UTP

Unshielded Twisted Pair. Standard network cable without shielding. Category 5e (1 Gbps), Cat 6 (10 Gbps up to 55m), Cat 6a (10 Gbps up to 100m).

Networking

VAN

Value Added Network. Third-party network provider for secure business communication. Used for EDI, procurement, supply chain integration.

Networking

VGA

Video Graphics Array. Legacy analog video connector. 15-pin D-sub. Replaced by HDMI and DisplayPort. Susceptible to EMI/signal degradation over distance.

Hardware

VLan

Virtual Local Area Network. Network segmentation using software. Isolates traffic without physical separation. Used for security and network optimization.

Networking

VNC

Virtual Network Computing. Cross-platform remote desktop protocol. Port 5900. Less efficient than RDP but works cross-OS. Always protect behind VPN/SSH tunnel.

Networking

VPN

Virtual Private Network. Encrypts traffic and routes it through a private server. Secures data on public Wi-Fi. Protocols: IKEv2, IPSec, L2TP, WireGuard.

Security

VR / AR / MR

Virtual Reality (fully immersive digital environment) / Augmented Reality (digital overlays on real world) / Mixed Reality (interactive blend). Used in gaming, training, design.

Mobile

WAN

Wide Area Network. Connects distant locations across cities/countries. Example: branch offices connected via dedicated lines or internet.

Networking

WPA / WPA2 / WPA3

Wi-Fi Protected Access. Security standards. WPA (TKIP - weak), WPA2 (AES/CCMP - strong), WPA3 (SAE - strongest, protects against brute-force). Use WPA3 when available.

Security

Wi-Fi 6 / 6E / 7

Wi-Fi standards. 802.11ax (9.6 Gbps, 2.4/5 GHz). 6E extends to 6 GHz. 802.11be (46 Gbps with MLO). Higher = faster, less interference, better for dense environments.

Networking

WWAN

Wireless Wide Area Network. Cellular connectivity (4G/5G). Used by smartphones and mobile broadband cards for remote/mobile access.

Mobile
