Windows Utilities & Power Tools (Free)

Microsoft PowerToysFree

Collection of productivity utilities for Windows — FancyZones, PowerRename, Image Resizer, Color Picker, and more.

Sysinternals SuiteFree

Advanced system utilities by Mark Russinovich. Process Explorer, Autoruns, TCPView — indispensable for troubleshooting.

Windows TerminalFree

Modern terminal with tabs, panes, and Unicode support. Replaces cmd.exe for daily use.

TreeSize FreeFree

Visualize disk space usage. Shows what's eating your storage in a tree view.

WizTreeFree

Ultra-fast disk space analyzer. Reads MFT directly for instant results.

BleachBitFree

Open-source system cleaner. Removes junk files safely without privacy concerns.

DropItFree

Free, open-source, portable file organizer. Auto-sorts messy folders (like Downloads) by type, name, or rule — a solid alternative to paid folder-cleanup tools.

Revo Uninstaller (Free)Free

Complete uninstaller that removes leftover registry entries and files.

NiniteFree

Batch-installs common free tools (7-Zip, VS Code, and more) silently, with no bundled toolbars or offers.

Hardware & Diagnostics (Free)

CPU-ZFree

Detailed hardware info: CPU, RAM, motherboard, GPU specifications.

HWiNFOFree

Comprehensive hardware monitoring and reporting. Real-time sensors.

CrystalDiskInfoFree

S.M.A.R.T. monitoring for HDDs and SSDs. Predict drive failures.

EaseUS Todo Backup FreeFree

Free disk/partition imaging and backup software. Great for practicing full, incremental, and differential backup concepts.

MemTest86Free

Industry-standard RAM testing tool. Boot from USB to test memory.

RufusFree

Create bootable USB drives. Essential for OS installations and diagnostics.

VentoyFree

Boot multiple ISOs from one USB drive. No need to reformat for each ISO.

Virtual CloneDriveFree

Mount ISO, BIN, and other disc images as a virtual CD/DVD/Blu-ray drive — no burning required.

GPartedFree

Free, bootable partition editor. Resize, create, and format partitions — pairs well with Rufus/Ventoy.

RecuvaFree

Free deleted-file recovery tool. Note: the installer may offer bundled add-ons — watch for opt-out checkboxes during setup.
