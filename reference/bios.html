BIOS/UEFI Settings Quick Reference

Key firmware settings for the CompTIA A+ 220-1200 exam — know what each does and when to change it

Setting Purpose Exam Relevance
Boot Order Determines which device boots first (HDD, USB, Network/PXE) Change when installing OS or troubleshooting boot issues
Secure Boot Only allows OS with trusted certificates to boot Required for Windows 11. Prevents rootkits. Must disable for some Linux
TPM Trusted Platform Module activation Required for BitLocker and Windows 11. Stores encryption keys
Virtualization (VT-x/AMD-V) Enables hardware virtualization support Must be ON for Hyper-V, VirtualBox, VMware. Off by default on some systems
CSM (Compatibility Support Module) Legacy BIOS compatibility mode Disable for Secure Boot/GPT. Enable only for legacy OS installs
XMP/DOCP Enables RAM beyond stock speed (overclocking profiles) Not exam-tested but common troubleshooting for instability
Fan Control Set fan curves and temperature thresholds Overheating issues. CPU_FAN header must be populated
Wake-on-LAN Allow network packet to power on system Used for remote management, PXE boot, enterprise deployment
POST Diagnostics Beep codes and LED indicators for failed components No beep = dead PSU/mobo. Repeating beeps = RAM. Check vendor manual
Password (Supervisor/User) Lock BIOS settings or require password to boot Supervisor = change settings. User = boot only. Clear via CMOS reset
UEFI vs Legacy Mode Modern (UEFI+GPT) vs Legacy (BIOS+MBR) boot Windows 11 requires UEFI. Drives >2TB require GPT/UEFI
Date/Time System clock Wrong time = SSL cert errors, failed updates. Dead CMOS battery if resets

🎯 Exam Tips

  • Can't install Windows 11? Check: UEFI mode ON, Secure Boot ON, TPM 2.0 enabled
  • System won't boot from USB? Check boot order AND CSM/Legacy settings
  • BIOS clock resets every boot = dead CMOS battery (CR2032)
  • Hyper-V won't start? Enable Virtualization (VT-x) in BIOS first
  • NEVER set a BIOS password you might forget — CMOS reset is the only recovery
